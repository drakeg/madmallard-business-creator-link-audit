One-time setup

  1. Open YouTube Data API v3 in Google Cloud.
  2. Select your Google API project and enable YouTube Data API v3.
  3. Create an API key and restrict it to YouTube Data API v3. Server-side requests must be allowed from this Mac; browser-referrer restrictions do not apply to this server workflow.
  4. Paste that key in the field here. Keep within your API quota; no billing, purchases or quota increases are performed by this app.

Optional local operator setup: set YOUTUBE_API_KEY in this app's .env and recreate only its web service. The app continues running locally; requests for public metadata go to YouTube.

This imports public descriptions only. It does not sign into your Google account, access private videos, download videos or modify YouTube.
